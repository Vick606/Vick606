I build tools that make AI systems measurable and harder to break: detecting prompt injection buried in agent tool outputs, running repositories in isolated environments, and producing structured reports that downstream systems can trust.

### Recent work

**[Subcanopy Guard](https://github.com/Vick606/subcanopy-guard)** — context-aware indirect prompt injection scanner for AI agent tool outputs. Sliding-window density plus stylometric discontinuity.

`86.5% caught on AgentDojo v1` · `0.85 ms per scan` · `zero runtime dependencies` · `pip install subcanopy-guard`

**[RepoProbe](https://github.com/Vick606/repo-probe)** — clone, containerize, and test any Python repo, then emit a structured JSON evaluation report.

`v0.1.0 shipped` · `22 unit tests passing` · `verified on pallets/click`
